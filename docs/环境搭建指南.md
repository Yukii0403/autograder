## 第 0 步 先理解一件事：CPU 时间限制怎么算

这一步必须看懂，否则后面会踩坑。

Cloudflare Workers 的 `10ms CPU` 限制（Free 版）**只计算 CPU 实际执行时间，不计算等待网络的时间**。

| 操作 | 算不算 CPU 时间 | 说明 |
|---|---|---|
| 调用 DeepSeek API 等 20 秒 | ❌ **不算** | `fetch()` 的等待期间 Worker 不消耗 CPU |
| 调用 `env.AI.toMarkdown()` 解析 PDF | ❌ **不算** | 这是平台服务调用，不是本地计算 |
| Hono 路由匹配、JSON 解析 | ✅ 算 | 但很便宜，通常 < 1ms |
| Zod 校验一个 5KB 的 JSON | ✅ 算 | 约 1–3ms |
| 用 `indexOf` 做引文回查 | ✅ 算 | 原生实现，很快 |
| **用 `unpdf` 在本地抽取 10 页 PDF 文本** | ✅ **算，而且很贵** | 要遍历对象树、解压流，可能几十到几百 ms |

**结论：整个架构里唯一吃 CPU 的大户就是本地 PDF/DOCX 解析。把它挪走，Free 版就够用。**

## 第 1 步 注册 Cloudflare 并开通 Workers

### 1.1 注册账号（免费）

1. 打开 https://dash.cloudflare.com/sign-up
2. 用邮箱注册，设置密码
3. 去邮箱点验证链接

> 你之前部署过 `academic-nav.yukii0403.workers.dev`，说明**账号和 workers.dev 子域已经开通了**，这一步可以跳过，直接登录。

### 1.2 确认 Workers 已启用

1. 登录 https://dash.cloudflare.com
2. 左侧菜单找 **Workers & Pages**
3. 能看到已有的 Worker 列表就说明已启用

如果提示需要设置子域，填一个你喜欢的名字（比如 `yukii0403`），最终域名就是 `<名字>.workers.dev`。

### 1.3 【先不要做】升级 Paid

**先不要点升级。** 原因有两个：

1. **Free 版对本方案够用**（见第 0 步），省下 $5/月
2. **开通 Paid 需要绑定信用卡**（Visa / Mastercard）。国内大部分银联卡不支持，这会是你的实际障碍

只有在**第 6 步的撞限信号真的出现，且确认无法用其他方式规避**时，再回来处理。那时你需要的是一张双币信用卡。

## 第 2 步 本地登录 wrangler

`wrangler` 是 Cloudflare 的官方 CLI，会作为开发依赖装在项目里。

```bash
cd D:\Learnbuddy\2026-09-18-12-36-17\autograder

# 安装依赖（这一步会把 wrangler 装到 node_modules）
npm install

# 登录（会打开浏览器让你授权，和刚才 GitHub 那次一样）
npx wrangler login

# 确认登录成功
npx wrangler whoami
```

`whoami` 能打印出你的账号邮箱和 Account ID 就对了。

> 授权方式和刚才 `gh` 那次一样，是浏览器 OAuth。如果浏览器没自动弹出，把终端里的 URL 复制出来手动打开。

## 第 3 步 配置 DeepSeek API Key

### 3.1 本地开发用 `.dev.vars`

`.dev.vars` 是 wrangler 读取本地环境变量的文件，**已经被 `.gitignore` 排除，不会被提交**。

```bash
cd D:\Learnbuddy\2026-09-18-12-36-17\autograder

# 从模板复制
copy .dev.vars.example .dev.vars
```

然后用编辑器打开 `.dev.vars`，把这行：

```
DEEPSEEK_API_KEY="sk-REPLACE_ME"
```

改成你自己的 Key：

```
DEEPSEEK_API_KEY="sk-你的真实key"
```

### 3.2 生产环境用 secret

部署到线上时，Key **不能**写进代码或配置文件，要用 wrangler secret：

```bash
npx wrangler secret put DEEPSEEK_API_KEY
# 回车后会提示你粘贴，粘贴后回车即可
```

secret 存在 Cloudflare 侧，只有 Worker 运行时能读到，前端看不到。

### 3.3 顺手确认两件事

1. **模型 ID**：打开 DeepSeek 开放平台 https://platform.deepseek.com 的文档页，确认当前可用的模型名。方案里默认写的是 `deepseek-flash`，如果你的账号里叫别的名字，改 `.dev.vars` 里的 `DEEPSEEK_MODEL`。
2. **余额**：DeepSeek 的 API 是预付费的，确认账户里有余额。按我们的测算，30 份报告大约 ¥3，充 10 块够你开发很久。

### 3.4 ⚠️ 安全提醒

**不要把 API Key 贴到聊天里。** 写进 `.dev.vars` 就好，我会从那里读。如果那个 Key 曾经以任何形式暴露过（贴过群、截过图、提交过代码），去平台后台**重新生成一个新 Key**，旧作废。

## 第 4 步 建 R2 与 D1

两个存储都要建。**这两个在免费额度内完全够用。**

```bash
# 建 D1 数据库（存结构化记录）
npx wrangler d1 create autograder

# 建 R2 存储桶（存原始文件与解析产物）
npx wrangler r2 bucket create autograder-files

# 确认
npx wrangler d1 list
npx wrangler r2 bucket list
```

`d1 create` 会打印一段配置，你需要把它贴到 `wrangler.jsonc` 里（大概长这样）：

```jsonc
{
  "d1_databases": [
    { "binding": "DB", "database_name": "autograder", "database_id": "<粘贴这里>" }
  ]
}
```

否则 Worker 里 `env.DB` 会是 undefined。

## 第 6 步 什么时候需要升 Paid

### 撞限的信号

如果本地解析做得太重，你会看到这样的错误：

```
Error 1102: Worker exceeded CPU time limit (10 ms)
```

或者任务莫名其妙失败、日志里出现 `exceededCpu`。

### 优先尝试的规避方式（0 成本）

按顺序试，**第一条就能解决大部分情况**：

| 顺序 | 做法 | 效果 |
|---|---|---|
| 1 | **PDF / DOCX 文本抽取改用 `env.AI.toMarkdown()`** | 服务调用，不计本地 CPU。这是主要解法 |
| 2 | 浏览器端做即时预览解析，Worker 只处理纯文本 | 进一步减轻本地负担 |
| 3 | 大 JSON 用轻量手写校验替代重量级 Zod schema | 省 1–3ms |
| 4 | 引文回查放到 Worker 之外（或用更省的做法） | 省几 ms |

### 真要升级时

Dashboard → Workers & Pages → Plans → 选 **Workers Paid**（$5/月，约 ¥36）。

**需要 Visa / Mastercard 双币信用卡。** 如果拿不到卡，就走上面四条规避路径——按目前设计，它们是能撑住的。

## 卡住的时候

按这个顺序排查：

1. `npx wrangler whoami` —— 登录是否正常
2. `npx wrangler tail` —— 看线上实时日志（比猜有用得多）
3. `/health` 与 `/ready` —— 区分"服务没起来"和"依赖不可用"
4. 报 `env.XXX is undefined` —— 九成是 `wrangler.jsonc` 里的 binding 名字和代码里读的对不上
5. 报 `CONFIG_MISSING` —— 环境变量没配全，错误信息里会指明缺哪个
